# 🌿 Greenleaf Academy LMS

Платформа для обучения и аттестации новых партнеров компании Greenleaf. Система автоматизирует процесс ввода новичков в бизнес, проверяет знания и выдает сертификаты.

## 🚀 Особенности проекта
*   **Последовательное обучение:** Уроки открываются только после сдачи теста за предыдущий этап.
*   **Автоматическая аттестация:** Система сама проверяет ответы и блокирует доступ при низком балле.
*   **Личный кабинет партнера:** Отслеживание прогресса, статус "Новичок/Партнер" и статистика.
*   **Генерация сертификатов:** Возможность скачать и распечатать персональный сертификат партнера.
*   **Адаптивный дизайн (PWA):** Полная поддержка мобильных устройств, возможность установки как приложение на телефон.
*   **Удобная админ-панель:** Интуитивно понятный интерфейс для методистов (вопросы и ответы редактируются вместе).

## 🛠 Технологии
*   **Backend:** Python, Django 6.1
*   **Frontend:** HTML5, CSS3 (Flexbox), Vanilla JS
*   **Database:** SQLite (легко заменяется на PostgreSQL)

## ⚡️ Быстрый старт

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ТВОЙ_НИК/greenleaf-academy.git
    cd greenleaf-academy
    ```

2.  Создайте виртуальное окружение и установите зависимости:
    ```bash
    python -m venv venv
    source venv/bin/activate  # Для Mac/Linux
    venv\Scripts\activate     # Для Windows
    pip install -r requirements.txt
    ```

3.  Примените миграции базы данных:
    ```bash
    python manage.py migrate
    ```

4.  Создайте суперпользователя (администратора):
    ```bash
    python manage.py createsuperuser
    ```

5.  Запустите сервер разработки:
    ```bash
    python manage.py runserver
    ```

6.  Откройте браузер: `http://127.0.0.1:8000/`
